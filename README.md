# 📋 Kunlik Reja (Daily To-Do & Checklist)

Mobil va kompyuter uchun juda sodda, tezkor va qulay kunlik vazifalar checklisti.

## 🚀 Xususiyatlari:
- 📱 **Mobil uchun qulay (PWA):** Telefonda "Bosh ekranga qo'shish" qilsa, ilovadek ochiladi.
- ⚡ **Offline ishlash:** Internet bo'lmaganda ham bemalol ishlaydi (Service Worker & LocalStorage).
- ✅ **Bajarilganini belgilash:** Bir marta bosish orqali checkbox qo'yiladi va chiziladi.
- 📊 **Progress bar:** Kun davomida qancha foiz ish bajarilganini hisoblab boradi.
- 🌓 **Dark / Light mode:** Tungi va kunduzgi rejim.
- 🖨 **Chop etish:** Qog'ozga yoki PDF qilib chiqarish imkoniyati.
- 💾 **Zaxiralash:** Vazifalarni JSON formatda saqlab olish (Export).
