# 🏆 RejaPro — Professional Samaradorlik va Hayot Rejalari Tizimi

RejaPro — shaxsiy va professional maqsadlarga erishish uchun mo'ljallangan keng qamrovli, tezkor va zamonaviy web-ilova.

🌐 **Jonli sayt:** [https://jurabekkholiqov.github.io/kunlik-reja/](https://jurabekkholiqov.github.io/kunlik-reja/)

---

## 🌟 Asosiy Imkoniyatlar:

1. 📅 **Kunlik Reja (Daily Planner):**
   - Istalgan sanaga o'tish (Oldingi kun, Bugun, Ertaga yoki Kalendardan tanlash).
   - Har bir kunga alohida reja va foiz hisobi.
   - Vazifalar uchun ustuvorlik darajasi (🔴 Yuqori, 🟡 O'rtacha, 🟢 Oddiy).
   - Kategoriyalar: 💼 Ish, 📚 O'qish, 👤 Shaxsiy, 🏃 Sog'liq.
   - Barcha vazifalar bajarilganda tabriklovchi **Confetti 🎉** animatsiyasi.

2. 📆 **Haftalik Reja (Weekly Sprint):**
   - Hafta davomida bajarilishi lozim bo'lgan eng muhim maqsadlar.
   - Hafta bo'yicha progress hisoblagichi.

3. 🗓️ **Oylik Marralar (Monthly Goals):**
   - Joriy oy uchun katta marralar va topshiriqlar.

4. 🎯 **Yillik Strategik Maqsadlar (Yearly Vision):**
   - Yil davomidagi global rejalar (Masalan: Chet tili, Yangi kasb, Avtomobil, Investitsiya).
   - Har bir maqsad uchun **Progress Slayderi (0% dan 100% gacha)**.

5. ⚡ **Odatlar Trekeri (Habit Tracker):**
   - Kundalik foydali odatlar (Kitob o'qish, Sport, Suv ichish).
   - Ketma-ketlik (Streak 🔥) hisoblagichi.
   - Oxirgi kunlar tarixi.

6. ⏱️ **Pomodoro Fokus Taymeri:**
   - 25 daqiqa chuqur diqqat, 5 daqiqa tanaffus.
   - Web Audio API orqali yumshoq ovozli signallar.

7. 📊 **Tahlil & Statistika (Analytics Dashboard):**
   - Jami bajarilgan ishlar statistikasi.
   - Motivatsion tavsiyalar.

8. 📱 **Mobil uchun PWA (Progressive Web App):**
   - Telefonda "Bosh ekranga qo'shish" orqali mustaqil mobil ilovaga aylanadi.
   - 100% Offline (internetsiz) rejimda to'liq ishlaydi.
   - Qurilma xotirasida avtomatik saqlanish (LocalStorage).
   - Zaxira nusxa olish (Export JSON) va qayta tiklash (Import).
